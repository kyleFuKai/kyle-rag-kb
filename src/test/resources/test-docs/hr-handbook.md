# 星舟实验室员工手册（虚构测试版）

本文面向虚构的星舟实验室员工，仅用于文档解析与知识库检索测试。文中的制度、金额和流程均为编写的示例，不代表任何真实公司的安排。阅读时请结合章节标题理解适用条件，遇到特殊情况应先向直属负责人说明，再按照对应流程提交申请，避免把不同场景的规定混用。

## 一、入职与试用期

新员工应在入职当天领取办公设备、完成账号激活并阅读信息保护说明。人事专员负责核对入职清单，直属负责人负责介绍团队职责和安排入职伙伴。第一周以熟悉产品、开发环境和协作流程为主，不要求独立承担紧急上线任务。**试用期统一设为三个月**，负责人在第一个月末和第三个月末分别进行沟通，记录工作目标、实际进展和需要的支持。岗位职责发生变化时，应重新确认目标，不以口头约定替代书面记录。

### 入职材料清单

- 完成虚构员工编号登记，示例编号为 LAB-TEST-017。
- 确认设备领用记录和办公软件使用范围。
- 与入职伙伴预约一次产品演示和一次项目结构介绍。

## 二、工作时间与协作

团队实行每周五天工作制，标准办公时间为九点三十分至十八点三十分，午间休息一小时。员工可在负责人知情的情况下调整当天到岗时间，但应保证核心协作时段十点至十七点能够联系。远程办公原则上每周最多两天，应在前一个工作日登记。线上会议开始前应提供议题和相关材料，会议结束后由组织者整理决定、负责人和完成时间。*异步沟通优先记录背景和预期结果*，紧急故障则使用团队值班渠道并同步工单。

## 三、休假与考勤

请假申请应明确开始时间、结束时间、假别以及交接人员。普通事假原则上提前两个工作日提交，连续三天及以上的假期需提前五个工作日申请。临时生病或突发家庭事务可先联系负责人，再于恢复办公后的两个工作日内补录。示例制度中，每自然年提供十二天福利年假，入职当年按实际服务月份折算，离职结算以人事确认记录为准。休假期间不安排例行交付任务，交接文档应写明待办事项、风险和紧急联系人角色。

| 假别 | 申请时间 | 审批角色 | 交接要求 |
| --- | --- | --- | --- |
| 福利年假 | 提前两个工作日 | 直属负责人 | 列出进行中的事项 |
| 连续长假 | 提前五个工作日 | 直属负责人及人事 | 指定交接人员 |
| 临时病假 | 及时告知后补录 | 直属负责人 | 说明紧急待办 |

## 四、差旅与费用报销

员工出差前应填写目的地、业务目标、预计日期和预算，审批完成后再预订交通与住宿。示例住宿上限为每人每晚四百五十元，市内交通按实际合理支出报销，餐费补贴为每天八十元。同一事项不得同时领取补贴并报销同类费用。费用发生后三十个自然日内应提交报销单，附上有效凭证和业务说明。遗失凭证或实际费用超预算时，应补充原因并取得负责人确认，财务在材料齐全后的十个工作日内安排审核。

1. 出差前提交预算并获得审批。
2. 返回后整理凭证，填写费用所属项目。
3. 由直属负责人确认业务真实性，再交财务审核。
4. 在报销系统查看退回原因或付款进度。

## 五、学习资源与内部支持

团队每月最后一个星期五安排内部分享，主题可包括产品使用、开发实践和故障复盘。员工每半年可申请一千二百元学习预算，用于与岗位相关的课程或书籍，购买前应说明学习目标，完成后提交简短的学习记录。参与内部分享不占用个人学习预算。遇到账号问题联系内部支持角色，遇到薪酬或休假问题联系人事角色，遇到费用问题联系财务角色。示例导航地址为[员工服务入口](https://example.com/employee-service)，链接仅用于测试。

## 六、信息保护与开发配置

工作资料应存放在团队指定位置，向外分享前确认接收范围和访问期限。测试数据不得包含真实个人信息，演示环境应使用独立账号和虚构记录。程序配置中的密码与访问凭证通过环境变量提供，不能写进代码或提交到版本库。以下代码块是 Spring Boot 的示例配置，应用名称和文件大小仅用于解析测试；块内井号表示配置注释，不是手册的新章节。发现疑似泄露时，应停止传播、保留必要记录并联系安全值班角色。

## 七、离职交接与手册反馈

员工提出离职后，应与负责人共同确认交接计划和最后工作日。交接范围包括进行中的任务、文档位置、业务风险、设备清单以及需要转移的系统权限，禁止通过转交个人密码完成权限移交。负责人确认业务交接，人事确认手续和假期记录，行政确认设备归还，内部支持负责在约定时间停用账号。对本手册有疑问时，可在[制度反馈页面](https://example.com/policy-feedback)提交章节名称、具体场景和建议，更新后的制度应注明生效时间。
